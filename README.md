# Misiones Web Arena

Repositorio de entregas de la asignatura Programación Web I: El Cliente.

## Misiones

### Misión 1 · El Despertar del DOM

Juego hecho con HTML, CSS y JavaScript para practicar la manipulación del DOM, los eventos, las funciones y la delegación de eventos.

El código y la documentación están en `Mision1/`.

### Misión 2

Segunda entrega de la asignatura. El proyecto y su documentación están en `Mision2/`.

### Misión 3 · React Core

Lista de tareas de estudio hecha con React y Vite. Permite añadir tareas, marcarlas como terminadas, borrarlas y filtrarlas. También se puede elegir una tarea pendiente al azar.

Se usan componentes, props, `useState`, `useEffect` y `localStorage` para guardar las tareas al recargar la página.

Para ejecutar la misión:

```bash
cd Mision3
npm install
npm run dev
```

La documentación de esta entrega, incluido el uso de IA y la autopsia, está en `Mision3/README.md`.
